SQL Cheatsheet

Las consultas típicas de los ejemplos, sobre las tablas de siempre. Cada tarjeta tiene la query, el resultado y la clave. Los resultados salen de ejecutar cada consulta en SQLite al generar la página.

Las tablas

Orden en que se evalúa

FROM / JOIN→WHERE→GROUP BY→HAVING→SELECT→ORDER BY→LIMIT

WHERE filtra filas (no ve agregados ni alias). HAVING filtra grupos. La izquierda de un JOIN es la tabla del FROM.

DDL: CREATE · ALTER · DROP · TRUNCATE · DML: SELECT · INSERT · UPDATE · DELETE · DCL: GRANT · REVOKE · TCL: COMMIT · ROLLBACK · SAVEPOINT

Filtrar filas

01

WHERE simple

SELECT nombre
FROM clientes
WHERE pais = 'AR';
Resultado · 2 filas
nombre
Ana
Caro

Filtra filas. Texto entre comillas simples.

02

IN: varios valores

SELECT nombre, pais
FROM clientes
WHERE pais IN ('AR', 'CL');
Resultado · 3 filas
nombrepais
AnaAR
CaroAR
DaniCL

Es lo mismo que pais = 'AR' OR pais = 'CL'.

03

BETWEEN incluye los extremos

SELECT id, total
FROM facturas
WHERE total BETWEEN 50 AND 100;
Resultado · 3 filas
idtotal
10100
1150
1280

El 50 y el 100 entran: 3 filas.

04

LIKE: patrón de texto

SELECT nombre
FROM clientes
WHERE nombre LIKE 'A%';
Resultado · 1 fila
nombre
Ana

% = cualquier cantidad de caracteres. 'A%' = empieza con A.

05

IS NULL

SELECT nombre
FROM clientes
WHERE email IS NULL;
Resultado · 1 fila
nombre
Beto

La forma correcta de buscar faltantes.

06

= NULL: la trampa

SELECT nombre
FROM clientes
WHERE email = NULL;
Resultado · 0 filas
nombre
0 filas

0 filas, sin error. NULL = NULL da UNKNOWN y WHERE solo deja pasar TRUE.

07

FROM clientes

LIMIT 2;

Dani
Caro

DESC = de mayor a menor (Z→A). LIMIT recorta después de ordenar.

09

COUNT(*) vs COUNT(col)

SELECT COUNT(*), COUNT(email)
FROM clientes;
Resultado · 1 fila

COUNT(*) cuenta filas; COUNT(email) ignora el NULL de Beto.

COUNT(DISTINCT)

FROM clientes;
Resultado · 1 fila

AR, BR, CL: 3 valores distintos.

11

Agregados sobre toda la tabla

       MIN(total), MAX(total)

Sin GROUP BY: una sola fila para toda la tabla.

12

GROUP BY: uno por grupo

SELECT cliente_id, SUM(total) AS total
FROM facturas
GROUP BY cliente_id;
Resultado · 3 filas
cliente_idtotal
1150

En el SELECT: solo columnas del GROUP BY y agregados.

13

HAVING: filtrar grupos

SELECT cliente_id, SUM(total) AS total
FROM facturas
GROUP BY cliente_id
HAVING SUM(total) > 60;
Resultado · 2 filas
cliente_idtotal
1150
280

Filtro sobre un agregado → HAVING. En WHERE da error.

14

WHERE + GROUP BY + HAVING

SELECT pais, COUNT(*) AS cant
FROM clientes
WHERE email IS NOT NULL
GROUP BY pais
HAVING COUNT(*) > 1;
Resultado · 1 fila
paiscant
AR2

WHERE saca a Beto (filas) → agrupa → HAVING deja los grupos con más de 1.

23

CTE: WITH

WITH totales AS (
  SELECT cliente_id, SUM(total) AS t
  FROM facturas
  GROUP BY cliente_id
)
SELECT cliente_id, t
FROM totales
WHERE t > 60;
Resultado · 2 filas
cliente_idt
1150
280

Parte la consulta en pasos con nombre. Acá WHERE sí sirve: t ya es una columna.

26

ROW_NUMBER vs RANK

WITH cant AS (
  SELECT c.nombre, COUNT(f.id) AS n
  FROM clientes c
  LEFT JOIN facturas f ON f.cliente_id = c.id
  GROUP BY c.nombre
)
SELECT nombre, n,
  ROW_NUMBER() OVER (ORDER BY n DESC, nombre) AS rn,
  RANK() OVER (ORDER BY n DESC) AS rk
FROM cant;
Resultado · 4 filas
nombrenrnrk
Ana211
Beto122
Caro132
Dani044

Beto y Caro empatan: RANK les da 2 a los dos y salta al 4.
