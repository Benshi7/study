Reglas para el choice

  • Verificá etiqueta + definición + ejemplo: el distractor cambia una sola pieza.
  • "Cualitativo continuo" no existe. Binarias va en cualitativos.
  • En EDA (referencia): cualitativo = categórico, cuantitativo = numérico. Una binaria es categórica nominal.
  • Clasificá por los valores, no por el nombre de la columna.

Los 5 tipos de análisis

TipoPreguntaEjemplo del slide
Descriptivo¿Qué pasó?Promedio de edad = 23 años
Exploratorio¿Hay un patrón oculto?Varones de 23 a 25 con notas menores que las mujeres
Diagnóstico¿Por qué pasó?Un error en el pago explica la baja de ventas
Predictivo¿Qué va a pasar?Ventas 2022 → modelo para 2023
Prescriptivo¿Qué hacer?Ajustar precios para no perder clientes

Misma métrica en el tiempo = descriptivo. Cruce de variables = exploratorio (el EDA genera hipótesis para validar; la hipótesis sobre causas sigue siendo diagnóstico). Cuestionario #17: A-2, B-3, C-4, D-5, E-1.

DIKW

SABIDURÍA     juicio → decisiones estratégicas
CONOCIMIENTO  aplicar info para resolver
INFORMACIÓN   datos procesados + contexto
DATOS         hechos discontinuos

Insight: información de valor que ayuda a decidir y a plantear estrategias.

Flujo del Data Analyst

  1. Problema / pregunta
  2. Hipótesis
  3. Exploración y consultas
  4. Recopilar información de valor
  5. Visualizaciones
  6. Comunicar hallazgos (iterativo)

Generar información: fuentes → ETL → análisis → visualización → decisiones.
