DimensiónPregunta

Árbol de decisión

Falta obligatorio        → COMPLETITUD
Difiere entre sistemas   → CONSISTENCIA
Llega tarde / viejo      → TEMPESTIVIDAD
Registro repetido        → DUPLICADOS
Mal desde la carga       → PRECISIÓN
Formato/proceso mal      → CONFIGURACIÓN
Corrupto / truncado      → INTEGRIDAD

¿Estuvo bien alguna vez?

Nació mal (no cumple el estándar) → configuración · nació bien y se rompió → integridad · correcto pero tarde → tempestividad · contradice otra fuente → consistencia.

Completitud

  • Se mide contra la definición del negocio o del dueño del dato.
  • Un dato opcional no se considera.
  • Se mide por registro: 4 de 8 registros completos da 50%.

Data-driven

Usar datos y análisis para decidir y priorizar acciones.

RESISTANT → AWARE → GUIDED → SAVVY → DRIVEN
  1. Recopilación correcta de datos
  2. Herramientas orientadas al dato
  3. Nuevas áreas y perfiles (CDO)
  4. Data governance

Data governance

Autoridad, control y toma de decisiones compartida sobre los activos de datos (DAMA). Personas + procesos + tecnologías.

QUIÉN · QUÉ ACCIONES · QUÉ DATOS · CUÁNDO · SITUACIONES · MÉTODOS

Incluye definir roles y responsabilidades y crear políticas y procesos. Beneficios: calidad, estandarización, mejores decisiones, menos esfuerzo, seguridad y privacidad.
