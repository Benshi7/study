Fuentes: Kahoot y los notebooks de raw/notebooks/. Lecciones: 0007 a 0011.

Definiciones (Kahoot)

  • Python: lenguaje de código abierto, interpretado (sin compilar) · código → bytecode → VM
  • Librería: módulos y funciones reutilizables
  • Pandas: Series (1D) y DataFrame (2D)
  • Función: bloque que realiza una tarea; parámetros + return
  • IDE: entorno de desarrollo integrado → PyCharm (no Jupyter ni Colab)
  • Notebook: texto + código + resultados, por celdas
  • Colab: notebooks en la nube de Google
  • Variable: nombre que referencia un objeto en memoria
  • input() → siempre str
  • if cond: + indentación (4 espacios)
