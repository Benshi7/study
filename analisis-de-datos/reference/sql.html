SELECT

SELECT … FROM … WHERE … GROUP BY …
HAVING … ORDER BY … LIMIT …
-- evaluación:
FROM → WHERE → GROUP BY → HAVING
     → SELECT → ORDER BY → LIMIT
  • WHERE filtra filas · HAVING filtra grupos
  • COUNT(*) todas · COUNT(col) sin NULL
  • IS NULL, nunca = NULL
  • BETWEEN incluye los extremos · LIKE 'A%'

Taller

  • INNER = coincidencias · LEFT = toda la izquierda + NULL
  • LEFT JOIN + IS NULL = "sin facturas"
  • Subconsulta: > (SELECT AVG(...)) · CTE: WITH x AS (...)
  • OVER no colapsa filas · PARTITION BY reinicia por grupo
  • 100, 80, 80, 50 → ROW_NUMBER 1-2-3-4 · RANK 1-2-2-4
  • LAG = fila anterior · LEAD = fila siguiente · en los bordes, NULL
  • Física = largo plazo · temporal = intermedia
  • Índice: búsquedas más rápidas, inserciones más lentas
