Análisis exploratorio de datos (EDA): flujo, fórmulas y código

Fuentes: PDF 003 Análisis Exploratorio y notebooks 0 a 8 de material_eda/. Lecciones: 0016 a 0021.

Definición y flujo

EDA: explorar y resumir un conjunto de datos para comprender sus características, detectar patrones, identificar problemas y generar hipótesis. No establece causalidad.

  1. Definir preguntas: objetivo del análisis
  2. Conocer los datos: head · shape · dtypes · info
  3. Clasificar variables
  4. Evaluar la calidad: faltantes · duplicados · tipos incorrectos · inconsistentes · outliers
  5. Explorar y analizar: descriptivos · gráficos · correlación · segmentación

Fuentes: primaria (de primera mano, la controlamos) · secundaria (la recolectó otro: INDEC) · terciaria (compilada de varias fuentes).

Variables

  • Categórica nominal (sin orden) · ordinal (con orden) → frecuencias, barras, torta
  • Numérica discreta (contable) · continua (rango) → resumen, histograma, boxplot, dispersión
  • Unidad 1: cualitativo = categórico, cuantitativo = numérico; binaria → categórica
  • dtype ≠ tipo de variable: target int64 es categórica nominal

Problemas → tratamiento

  • Eliminar: no aporta o tiene errores graves
  • Corregir: se puede recuperar (formato, tipo)
  • Imputar: estimar con media, mediana o moda
  • En el EDA primero se detecta y mide; después se decide

Medidas descriptivas

  • Tendencia central: media · mediana · moda
  • Dispersión: mín, máx · rango · desvío estándar
  • Posición: cuartiles (4 partes) · percentiles (100 partes)
  • Lámina (2, 4, 4, 6, 10): media 5,2 · mediana 4 · moda 4 · rango 8 · Q1 3 · Q3 8. pandas da Q1 4 y Q3 6

Forma de la distribución

  • Simétrica: media ≈ mediana ≈ moda
  • Positiva (cola a la derecha): media > mediana → ingresos
  • Negativa (cola a la izquierda): media < mediana → puntaje con tope
  • Asimétrica → la mediana representa mejor
  • skew(): ≈ 0 simétrica · > 0 positiva · < 0 negativa

Fórmulas

  • Rice: k = ⌈ 2 · n1/3 ⌉ (n no nulos) · bins="rice"
  • RIC = Q3 − Q1 (50% central)
  • Li = Q1 − 1,5 · RIC · Ls = Q3 + 1,5 · RIC
  • Atípico: x < Li o x > Ls
  • z = (x − media) / desvío → media 0, desvío 1, misma forma
  • Lámina salarios: Q1 26 · Q3 41 · RIC 15 · Li 3,5 · Ls 63,5 · atípicos 2 y 75

Correlación

  • r ∈ [−1, 1]: signo = dirección, |r| = fuerza
  • ≈ 0,7–0,99 fuerte · ≈ 0,3–0,7 moderada · ≈ 0 sin relación lineal
  • Pearson: lineal, valores, sensible a outliers (default)
  • Spearman: monótona, rangos, robusta
  • Correlación ≠ causalidad (helados y ahogamientos, r = 0,89 → temperatura)
  • Outliers: r = 0,2 con, 0,8 sin
  • Signo vs target: target 0 = maligno → negativo = maligno · maligno 1 = M → positivo = maligno
