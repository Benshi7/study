Errores, bucles e imports

La primera mitad del notebook autoguiado de la clase 2: try/except, las cuatro excepciones que enseña la cátedra, for/while, break/continue, list comprehension y las formas de importar.

Manejo de errores

ExcepciónCausaEjemplo del notebook
ZeroDivisionErrorDivisión por cero10 / 0
ValueErrorEl tipo está bien pero el valor no sirveint("cuarenta")
IndexErrorPosición inexistente en una lista[1, 2, 3][10]
KeyErrorClave inexistente en un diccionariodatos["apellido"]

Un except genérico atrapa cualquier error, pero no dice cuál fue. Capturar la excepción específica permite dar mensajes claros y reaccionar distinto según el error.

Bucles

forwhile
Idea"Para cada elemento de esta secuencia…""Mientras se cumpla la condición…"
CuándoRecorrer una colección o repetir un número conocido de vecesCuando no sabemos cuántas vueltas habrá
Riesgo—Bucle infinito si la condición nunca se vuelve falsa
  • range(inicio, fin, paso): el fin NO se incluye. range(1, 101) da 100 vueltas; range(5, 0, -1) da 5, 4, 3, 2, 1.
  • enumerate(lista) devuelve pares (posición, elemento).
  • break termina el bucle completo · continue salta a la siguiente vuelta.
  • List comprehension: [n ** 2 for n in numeros] es lo mismo que un for con append(), en una línea.

Importar

FormaCómo se usa después
import mathmath.sqrt(25)
from math import sqrtsqrt(25)
import datetime as dtdt.date.today() (el alias es otro nombre, no otra librería)
from math import *Funciona, pero no se recomienda: no se sabe de dónde viene cada nombre

Instalar ≠ importar. !pip install pandas instala la librería en el entorno (el ! le dice a Colab que ejecute un comando del sistema). import pandas as pd la carga en el programa. La biblioteca estándar (math, random, datetime) viene con Python; las externas (pandas, matplotlib) pueden necesitar instalación.
