¿Qué es una base de datos?

Una colección organizada de datos estructurados, almacenados electrónicamente, diseñada para ser escrita, consultada, administrada y actualizada de forma eficiente. Tiene cuatro propiedades: organización (tablas, esquemas, relaciones), persistencia (los datos sobreviven al proceso que los creó), acceso eficiente y consistencia (reglas de integridad).

Sin base de datos hay Excel dispersos, datos duplicados y contradictorios, y no hay control de acceso. Con base de datos hay una fuente única de la verdad (Single Source of Truth), datos normalizados, roles y permisos, y relaciones explícitas.

Fuente: unicaba_fundamentos_sql.pdf, secciones 1 y 2.

Clasificá por el caso de uso, no por tu stack

En el slide, NoSQL = documental. La columnar va aparte: "Relacionales, NoSQL, columnares y más". La pregunta siempre te da una palabra clave del caso de uso:

  • Facturación o stock: relacional.
  • Atributos variables: documental.
  • Sesiones o carrito: clave-valor.
  • Dashboards o millones de registros: columnar.
  • Recomendaciones: grafos.
  • Sensores: time series.

El tipo se refiere al motor. Un Postgres con una columna JSONB sigue siendo relacional, y analizar esos datos después en Databricks o con pandas no convierte la base de origen en columnar.

El modelo relacional

Propuesto por Edgar F. Codd en 1970. Organiza los datos en tablas (cada una representa una entidad) con filas y columnas, vinculadas mediante claves.

ComponenteQué es
Tabla (entidad / relación)Representa un objeto del mundo real: Clientes, Pedidos
Fila / tupla · Columna / atributoUn registro · una característica
Clave primaria (PK)Identificador único e irrepetible de cada fila
Clave foránea (FK)Columna que referencia la PK de otra tabla
Integridad referencialGarantiza que una FK siempre apunte a un registro existente en la tabla padre
1 : 1   Persona ─── DNI / Pasaporte        cada registro de A tiene exactamente uno en B
1 : N   Cliente ──< Pedidos                un cliente, muchos pedidos
N : M   Productos >──< Pedidos             se resuelve con una TABLA INTERMEDIA (Detalle_Pedido)
