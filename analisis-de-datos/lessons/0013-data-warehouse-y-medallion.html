Data Warehouse

Un DWH es una base de datos analítica centralizada que integra datos de múltiples fuentes operacionales, organizada para facilitar el análisis histórico y la toma de decisiones.

CaracterísticaOLTP (operacional)OLAP (Data Warehouse)
ObjetivoTransacciones del día a díaAnálisis e informes históricos
OperacionesINSERT, UPDATE, DELETESELECT (consultas complejas)
DatosActuales, detalladosHistóricos, agregados
UsuariosOperarios, sistemasAnalistas, directivos, BI
EjemplosCRM, ERP, e-commercePower BI, Tableau, Looker

Fact tableDimension table

Arquitectura Medallion

Patrón para organizar los datos en capas de refinamiento progresivo. Se usa mucho en Data Lakes y en plataformas como Microsoft Fabric, Databricks y Delta Lake.

CapaContenidoVocabulario del slide
BRONZE · raw / ingestaDatos crudos tal como llegan (CSV, APIs, tablas operacionales). Sin transformación. Se preserva el histórico completolanding zone · full load · sin limpieza
SILVER · cleaned / conformedDatos limpiados, validados y estandarizados: se eliminan duplicados, se corrigen tipos, se aplican reglas de negocio básicasODS · staging · datos normalizados
GOLD · business / curatedDatos agregados y modelados para consumo analítico: facts y dims, KPIs, métricasData Warehouse · Data Mart · Power BI
Conectá con el bloque 1

El paso de Bronze a Silver es el data cleansing de la lección 0002, donde se corrigen duplicados, consistencia y configuración. Gold es lo que consume el Data Analyst para generar insights. Y toda la cadena es la metáfora del "petróleo": extraer (Bronze), refinar (Silver) y distribuir (Gold).

"¿En qué capa se limpia?" → en la capa de destino

Cada capa es el dato más el proceso que lo produce. El job que lee Bronze, deduplica y escribe es el proceso de Silver. Por eso "se eliminan duplicados en Silver", aunque técnicamente ocurra "entre" las dos capas. Bronze nunca transforma: si lo limpiaras, dejaría de ser crudo. Regla: la transformación pertenece a la capa que resulta de ella. Limpiar es Silver; agregar y modelar es Gold.
