Lección 0014

SQL: sublenguajes, SELECT y agregación

Es la sección 6 de los slides. La cátedra dice: "en esta materia nos enfocaremos principalmente en DML, específicamente en el comando SELECT".

Antes de leer: recuperá de memoria

Sin mirar la 0013: ¿en qué capa Medallion se eliminan los duplicados? ¿Qué operaciones caracterizan a OLTP?

Qué es SQL y sus cuatro sublenguajes

Structured Query Language: el lenguaje estándar de las bases relacionales. Es declarativo: describís qué querés, no cómo obtenerlo.

SublenguajeComandosPara qué
DDL · Data DefinitionCREATE · ALTER · DROP · TRUNCATEDefine la estructura
DML · Data ManipulationSELECT · INSERT · UPDATE · DELETEManipula los datos
DCL · Data ControlGRANT · REVOKEControla accesos y permisos
TCL · Transaction ControlCOMMIT · ROLLBACK · SAVEPOINTGestiona transacciones
Trampa: TRUNCATE vs DELETE

Los dos "borran filas", pero para la cátedra TRUNCATE es DDL y DELETE es DML. Y SELECT está en DML, no en un sublenguaje aparte.

Anatomía y orden lógico

SELECT nombre, ciudad        ← qué columnas (* = todas)
FROM clientes                ← de qué tabla
WHERE segmento = 'Enterprise'← filtra FILAS  (AND, OR, NOT, IN, LIKE, BETWEEN)
GROUP BY ...                 ← agrupa para agregar
HAVING ...                   ← filtra GRUPOS (después de agregar)
ORDER BY nombre ASC          ← ordena (ASC / DESC)
LIMIT 10                     ← limita filas (TOP 10 en SQL Server)

Orden en que el motor lo EVALÚA:
FROM → WHERE → GROUP BY → HAVING → SELECT → ORDER BY → LIMIT
OperadorSignificado
= · != o <> · > < >= <=Comparación
AND · OR · NOTLógicos
IN (a, b) · BETWEEN x AND y (incluye los extremos) · LIKE 'A%'Especiales
IS NULL · IS NOT NULLNULL no es cero ni cadena vacía: es ausencia de valor. Nunca = NULL

Agregación

  • COUNT(*) cuenta todas las filas · COUNT(col) cuenta los valores no nulos de esa columna (slide: 1.500 vs 1.420).
  • SUM, AVG, MAX, MIN · COUNT(DISTINCT col) cuenta valores únicos.
  • DISTINCT elimina duplicados del resultado · AS pone alias a columnas y tablas, y permite columnas calculadas (monto * 1.21 AS monto_con_iva).

Buenas prácticas del slide: evitá SELECT *, usá alias con nombres de negocio, filtrá lo antes posible (WHERE antes de agregar) y comentá tus queries (--).
