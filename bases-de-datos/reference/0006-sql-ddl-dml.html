RestricciónFuerza…Detalle que toman

UNIQUEunicidad de otra columnaClave candidata.
DEFAULTvalor predeterminadoSe usa si el INSERT no trae la columna.
NOT NULLexistencia de valorSi no se declara nada, la columna acepta NULL.
CHECKdominioFALSO → error. VERDADERO → pasa. DESCONOCIDO (NULL) → pasa.

BDML: consultas

SELECT   [DISTINCT] S.Nombre, COUNT(*) AS Consultas     -- 5. proyectar
FROM     HISTORIA_CLINICA H                              -- 1. armar filas
JOIN     SERVICIO S ON S.Cod_Servicio = H.Cod_Servicio
WHERE    H.Fecha BETWEEN '2026-01-01' AND '2026-06-30'   -- 2. filtrar filas
GROUP BY S.Nombre                                        -- 3. agrupar
HAVING   COUNT(*) > 2                                    -- 4. filtrar grupos
ORDER BY Consultas DESC;                                -- 6. ordenar

DVistas

CREATE VIEW RRHH_Medicos AS
SELECT P.Cod_Profesional, P.Nombre,
       CASE WHEN EXISTS (SELECT * FROM PROFESIONAL S WHERE S.Cod_Jefe = P.Cod_Profesional)
            THEN 'SI' ELSE 'NO' END AS Es_Jefe,
       CASE WHEN P.Cod_Especialidad IN (2, 3) THEN 'SI' ELSE 'NO' END AS Especialidad_Riesgo,
       P.Cod_Profesional || '-' || SUBSTR(P.Nombre, 1, 6) || '-' || E.Nombre AS Identificador
FROM   PROFESIONAL P JOIN ESPECIALIDAD E ON E.Cod_Especialidad = P.Cod_Especialidad;

"Representación lógica de un subconjunto de datos de una o más tablas": guarda el SELECT, no las filas. Sirve para renombrar (Prod en inglés → vista en español), calcular derivados (la edad), simplificar JOINs y restringir acceso. Concatenar: || en SQLite y estándar, CONCAT() en MySQL, + en SQL Server.

EStore procedures y triggers

Store procedureTrigger
Qué es"Conjunto de instrucciones destinados a ejecutar un proceso específico.""Activa una determinada función cuando ocurre un cierto evento" en una tabla o vista.
Cómo correLo llaman: CALL nombre(args);Se dispara solo, por INSERT, UPDATE o DELETE.
RecibeParámetros IN / OUT.Las filas NEW / OLD.
Para quéVarias aplicaciones comparten el proceso; menos tráfico cliente–servidor; derivados más complejos.Reglas de negocio, auditoría, validación.
 
CREATE TRIGGER SueldoTotal1
AFTER INSERT ON EMPLEADO FOR EACH ROW              -- BEFORE: validar · AFTER: propagar · INSTEAD OF: vistas
WHEN (NEW.Dno IS NOT NULL)
  UPDATE DEPARTAMENTO SET SueldoTotal = SueldoTotal + NEW.Sueldo
  WHERE Dno = NEW.Dno;
