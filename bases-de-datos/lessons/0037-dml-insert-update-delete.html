Lección 37 · Unidad 5 · Lenguaje de consulta de datos

Cambiar los datos: INSERT, UPDATE, DELETE

Tres sentencias, más una combinación de dos. El INSERT … SELECT es el corazón técnico del TP5: así se puebla producción desde desarrollo.

~15 minutos Deck "DML", slides 34–37 · Consigna TP5, slides 4 y 7 Prioridad para el TP5: muy alta

01INSERT: dos formas

Con valores. Una fila, o varias separadas por coma:

INSERT INTO SERVICIO (Cod_Servicio, Nombre)
VALUES (6, 'Dermatología'),
       (7, 'Traumatología');

La lista de columnas es opcional, pero ponela siempre: sin ella, los valores tienen que venir en el orden exacto del CREATE TABLE, y un ALTER futuro rompe el script sin avisar.

Desde otra consulta. El SELECT reemplaza al VALUES:

INSERT INTO Prod_Service (Id_Service, Name_Service)
SELECT Id_Servicio, Nombre_Servicio
FROM   Desa_Servicio;
Esto es lo que pide la consigna del TP5

"Poblar las entidades de desarrollo con un (insert values). Poblar las entidades de producción desde las tablas de desarrollo (insert select)." El ejemplo de arriba es el del slide 7 de la consigna. Las columnas se emparejan por posición, no por nombre: la primera del SELECT va a la primera de la lista del INSERT. Por eso Id_Servicio puede caer en Id_Service.

02UPDATE y DELETE

UPDATE OCUPACION
SET    F_Hasta_Prevista = '2026-10-27'
WHERE  Cod_Paciente = 1;

DELETE FROM PREPAGA WHERE Cod_Prepaga = 4;
Sin WHERE, es toda la tabla

El deck lo muestra sin vueltas: DELETE FROM table; borra todo. UPDATE sin WHERE pisa todas las filas. Antes de correr un UPDATE o un DELETE, corré el mismo WHERE con un SELECT y mirá qué filas toca.

Y la integridad referencial sigue mandando: borrar OSDE, que tiene pacientes, falla por la FK de PACIENTE. Qué hacer en ese caso (CASCADE, SET NULL) se ve en la 0038.

03UPSERT

"Inserta una nueva fila si un identificador único especificado no existe, o actualiza una fila existente si el mismo identificador ya existe." 

INSERT INTO SERVICIO (Cod_Servicio, Nombre) VALUES (5, 'Kinesiología')
ON CONFLICT (Cod_Servicio)
DO UPDATE SET Nombre = excluded.Nombre;

excluded es la fila que intentaste insertar. Esta es la sintaxis de PostgreSQL y SQLite, la que muestra el deck. MySQL usa ON DUPLICATE KEY UPDATE y SQL Server usa MERGE.
