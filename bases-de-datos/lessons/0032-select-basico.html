Lección 32 · Unidad 5 · Lenguaje de consulta de datos

SELECT: qué columnas, qué filas, en qué orden

Una consulta de selección devuelve una tabla. Tres cláusulas deciden su forma: SELECT recorta columnas, WHERE recorta filas, ORDER BY las ordena.

~12 minutos Deck "DML", slides 3–8 y 14 Prioridad para el 2do parcial: alta

01Columnas: SELECT, DISTINCT y alias

SELECT   Nombre AS Paciente, F_Nacimiento
FROM     PACIENTE AS P;
  • SELECT * trae todas las columnas; listar los nombres trae sólo esas. En álgebra relacional, esto es la proyección.
  • SELECT DISTINCT "elimina las filas duplicadas y muestra una lista única de valores". Mira la fila entera que devolvés, no una columna suelta.
  • Un alias es "un nombre temporal" para una tabla o columna que "sólo existe mientras dura esa consulta". El AS es opcional: FROM PACIENTE P vale igual.
Por qué al TP5 le importan los alias

La consigna pide vistas "apuntando a producción con sus campos en español". Las tablas Prod tienen columnas en inglés, así que cada columna de la vista es un alias: Tower_Id AS Id_Torre. Esta es la herramienta que vas a usar ahí (0039).

02Filas: WHERE, AND, OR

SELECT Cod_Habitacion, Piso, Numero
FROM   HABITACION
WHERE  Cod_Torre = 1 AND Posee_Ventana = 'S';

WHERE extrae "sólo los registros que cumplan con una condición". AND exige las dos; OR, cualquiera de las dos.

AND se evalúa antes que OR

WHERE Cod_Torre = 1 OR Cod_Torre = 2 AND Posee_Ventana = 'S' se lee como Cod_Torre = 1 OR (Cod_Torre = 2 AND Posee_Ventana = 'S'): trae toda la torre 1, con o sin ventana. Cuando mezcles los dos, poné paréntesis siempre.

03Orden: ORDER BY

Ascendente por defecto; DESC lo invierte. Se puede ordenar por varias columnas: ORDER BY Cod_Torre, Piso DESC ordena por torre y, dentro de cada torre, por piso de mayor a menor. Sin ORDER BY, el orden de las filas no está garantizado, aunque parezca estable.
