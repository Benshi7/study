§1 — Probabilidad Básica

Definiciones de probabilidad

NombreFórmulaCuándo
Laplacefavorables / posiblesEspacio equiprobable
Frecuencialéxitos / ensayosAproximación empírica
AxiomáticaP(A)≥0, P(E)=1, aditividadBase formal

Relaciones entre sucesos

TérminoCondición
ExcluyentesA∩B = ∅
IndependientesP(A∩B)=P(A)·P(B) — equivalente a P(A)=P(A/B)
ExhaustivosA∪B = E (pueden solaparse)
ComplementariosExhaustivos Y excluyentes a la vez
Independientes ⇒ NO excluyentes (salvo trivial P=0). Excluyentes ⇒ NO independientes (salvo trivial).

Combinación de sucesos

SituaciónFórmula
A o B, excluyentesP(A)+P(B)
A o B, generalP(A)+P(B)−P(A∩B)
A y B, independientesP(A)·P(B)
A y B, dependientesP(A)·P(B/A)
CondicionalP(B/A) = P(A∩B)/P(A)
Con reposición → independiente. Sin reposición → dependiente. Si el enunciado NO aclara: se asume sin reposición.

Probabilidad total y Bayes

PreguntaFórmula
Total: "¿P(B) en general?"P(B) = Σ P(Aᵢ)·P(B/Aᵢ)
Bayes: "ya ocurrió B, ¿causa Aₖ?"P(Aₖ/B) = P(Aₖ)·P(B/Aₖ) / Σ P(Aᵢ)·P(B/Aᵢ)

P(Aₖ/B) se llama probabilidad a posteriori. El denominador de Bayes ES la probabilidad total.

Traducción de enunciados

como máximo / a lo sumo kP(x ≤ k)
como mínimo / por lo menos kP(x ≥ k)
más de la mitadP(x > n/2)
menos de la mitadP(x < n/2)
ninguno / algunoP(x=0) / P(x≥1)
entre a y bP(a≤x≤b) = P(x≤b)−P(x≤a−1)

Parámetro (población: μ, σ, σ²) vs. Estadístico (muestra: x̄, S, S²).

Percentiles, cuartiles y posición

"El k% obtiene MÁS que X" → Pk_real = 100−k, no k. Leer de qué lado está el porcentaje.

§3 — Distribuciones Discretas

Variable aleatoria discreta (general)

Función de probabilidadP(r)≥0 ∀r ; ΣP(r)=1
Esperanzaμ = E(r) = Σ rᵢ·P(rᵢ)
Varianzaσ² = Σ(rᵢ−E(r))²·P(rᵢ)

Binomial vs. Poisson

AspectoBinomialPoisson
Cuándo usarn fijo de pruebas, p de éxitoTasa promedio por unidad de tiempo/espacio, sin n fijo
Parámetrosn, pλ = b·t
Dominio{0,...,n} acotado{0,1,2,...} sin cota
Esperanzan·pλ
Varianzan·p·qλ (=esperanza)
λ SIEMPRE se recalcula según la ventana de tiempo/espacio pedida: λ_nuevo = tasa · nueva_extensión. No reusar el λ dado en otra unidad.

Suma de variables aleatorias

μ(x₁±x₂) = μ(x₁)±μ(x₂)Esperanza de suma/resta
σ²(x₁±x₂) = σ²(x₁)+σ²(x₂)SIEMPRE se suma, aunque sea resta
σ²(k·x) = k²·σ²(x)Constante multiplicando, al cuadrado
σ²(k) = 0Una constante no tiene varianza
TCL: si x es Normal → suma exactamente Normal (cualquier n). Si x NO es Normal → suma aprox. Normal si n≥30. Binomial→Normal si n≥30 es un caso particular del TCL. Para proporciones la cátedra también usa el criterio n·p ≥ 15 y n·q ≥ 15.

§4 — Distribuciones Continuas y Muestreo

Distribución Normal

EstandarizaciónZ = (x−μ)/σ
Regla empíricaμ±1σ→68% · μ±2σ→95% · μ±3σ→99,7% (aprox.; el 95% exacto es μ±1,96σ)
Suma de n igualesμ_W = n·μ · σ_W = √n·σ
Parámetros desconocidosCon un percentil se despeja μ o σ; con dos percentiles, sistema de 2 ecuaciones para μ y σ
P(X=a)= 0 siempre (continua) → P(≤)=P(<), P(≥)=P(>)

Estandarizar permite usar una sola tabla de referencia para cualquier μ y σ.

Distribución muestral de la media

μ_x̄ = μLa media de las medias muestrales = media poblacional
σ_x̄ = σ/√nError estándar de la media (siempre ≤ σ)
Z = (x̄−μ)/(σ/√n)Estadístico para un promedio de muestra
x original Normal → x̄ Normal exacto (cualquier n). x original NO Normal → x̄ aprox. Normal solo si n≥30.

§5 — Intervalos de Confianza

CasoFórmula
σ conocidoIC(μ) = x̄ ± Z·(σ/√n)
σ desconocidoIC(μ) = x̄ ± t·(s/√n), ν=n−1
Tamaño de muestra, σ conocidon = (Z·σ/E)²
Tamaño de muestra, σ desconocidoMétodo iterativo (t depende de ν=n−1)
IC para una proporciónIC(p) = p̂ ± Z·√(p̂·q̂/n)
Tamaño de muestra, proporciónn = Z²·p̂·q̂ / E² (sin estimación previa de p: p̂ = 0,5)
Margen de error y amplitudE = (sup − inf)/2 · amplitud = 2E
Confianza inversa (σ conocido)Z = E·√n/σ → de ese Z sale el nivel de confianza
"Confianza 95%" es una propiedad del método repetido, NO la probabilidad de que μ esté en ESE intervalo particular ya calculado (μ es constante, no variable aleatoria).
n siempre se redondea hacia arriba (nunca al más cercano). Mayor confianza → intervalo más ancho. Mayor n → intervalo más angosto. t > Z siempre, para el mismo nivel de confianza. Con ν grande, t→Z.

§6 — Regresión y Correlación

Correlación (Pearson)r = Sxy/√(Sxx·Syy)Rango −1 a 1
Recta de regresiónŷ = a + b·x
Pendienteb = Sxy/Sxx = r·(Sy/Sx)
Ordenadaa = ȳ − b·x̄
DeterminaciónR² = r²Rango 0 a 1 (% de variabilidad explicada)
El signo de b siempre coincide con el signo de r. La recta pasa siempre por (x̄, ȳ). Σ residuos = 0; Σ residuos² = mínimo (por eso "mínimos cuadrados"). Umbral de la cátedra: |r|≥0,7 → fuerte; R²>0,5 → buen ajuste.
Correlación ≠ Causalidad, siempre. r=0 solo descarta relación LINEAL (puede haber curvilínea). Extrapolar fuera del rango de X observado es riesgoso.

TrampaResolución en una línea

Varianza vs. desvíoσ = √Var — nunca son el mismo número (salvo Var=0 o Var=1)

Percentil "al revés""el k% gana MÁS que X" → Pk_real = 100−k
AsimetríaMo > x̄ → negativa (no positiva, ojo con la intuición)
Interpretación del ICConfianza es del método, no del intervalo ya calculado
