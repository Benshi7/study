# Normal + Binomial ("al menos uno") — dominado; ajuste de enfoque pedagógico

El usuario resolvió bien la lección 0005 (combinación Normal→Binomial, P(Y≥1) vs P(Y>1)). Pero aclaró dos cosas importantes que cambian cómo enseñar de acá en adelante:

1. **No calcula distribuciones a mano.** Usa una app para estandarizar/buscar Z, y calculadora para media/varianza/desvío con datos tabulados. No hace falta entrenar aritmética manual extensa — el foco debe ser en **cuándo usar qué** y **qué significa el resultado**, no en el cálculo paso a paso con números largos.
2. **Pidió amplitud antes que profundidad.** Con ~7 días para el final, prefiere una pasada rápida cubriendo los tópicos PRINCIPALES de todas las unidades, y después volver a profundizar donde le surjan dudas puntuales — en vez de agotar cada trampa menor de cada bloque antes de avanzar (como se hizo con el bloque 01).

**Implicancia**: reducir el detalle aritmético en los ejemplos de las próximas lecciones (mostrar el paso conceptual, no cada cuenta), y acelerar el recorrido por unidades — una lección por concepto central en vez de una por cada trampa. Ver [[NOTES.md]] para el detalle completo.
