VA discreta: esperanza, varianza y CV

Una tabla de probabilidades, una esperanza, una varianza y un veredicto: ¿baja o alta fluctuación? Todo con números del TP3.

El problema

Una variable aleatoria discreta se describe con una tabla: los valores posibles x y la probabilidad P(x) de cada uno. Con esa tabla no se “promedia” nada que ya haya ocurrido: se calcula lo que se espera en el largo plazo (esperanza) y cuánto se aleja lo que ocurra de eso (varianza y desvío). La pregunta de interpretación es siempre la misma: ¿esa fluctuación es chica o grande en relación con lo esperado? Eso lo responde el CV.

Las fórmulas de la cátedra

QuéFórmulaNotas
Condición de distribuciónP(x) ≥ 0 y Σ P(x) = 1Siempre verifícala: si falta un dato (A, B, C), sale de aquí
Esperanzaμ = E(X) = Σ x·P(x)No tiene por qué ser un valor posible (en el dado, 3,5)
Varianzaσ² = Var(X) = Σ (x − μ)²·P(x) = Σ x²·P(x) − μ²Las dos formas dan lo mismo; la segunda es más corta
Desvíoσ = √Var(X)Mismas unidades que X
Coef. de variaciónCV = σ / μCV < 0,2 ⇒ baja fluctuación; CV > 0,2 ⇒ alta variabilidad o incertidumbre
Acumuladas: F(r) = P(X ≤ r) (izquierda) y G(r) = P(X ≥ r) (derecha). Con un dado: P(X < 5) = F(4) = 4/6; P(X > 5) = G(6) = 1/6; P(3 ≤ X ≤ 6) = F(6) − F(2) = 5/6. Su E = 3,5 y su Var = 2,917.

Ejemplo resuelto 1 — TP3, ejercicio 2 (autos vendidos un sábado)

Datos: X = autos vendidos. P(0) = 0,1; P(1) = 0,2; P(2) = 0,3; P(3) = 0,3; P(4) = 0,1. Se pide cuántos espera vender y la variabilidad absoluta y relativa.

Total1,02,15,71,29
  1. Verificación: 0,1 + 0,2 + 0,3 + 0,3 + 0,1 = 1 ✓
  2. Esperanza: E(X) = 0 + 0,2 + 0,6 + 0,9 + 0,4 = 2,1 autos. Se espera vender 2,1 autos un sábado.
  3. Varianza (forma corta): Σ x²P = 0 + 0,2 + 1,2 + 2,7 + 1,6 = 5,7; Var = 5,7 − 2,1² = 5,7 − 4,41 = 1,29. Con la forma larga, la última columna suma lo mismo: 1,29.
  4. Desvío: σ = √1,29 = 1,136 autos (variabilidad absoluta).
  5. CV: 1,136 / 2,1 = 0,54 (variabilidad relativa). Como 0,54 > 0,2 hay alta fluctuación: la dispersión es el 54 % de lo que se espera vender, así que la venta de un sábado es muy incierta.

Ejemplo resuelto 2 — TP3, ejercicio 3 (facturas procesadas por día)

Datos: el empleado A falta el 10 % de los días y el B el 8 %. Si va A se procesan 50 facturas; si solo va B, 25; si van ambos, solo A procesa (50). Construye la distribución y calcula E(X), indicando si la fluctuación es baja.
x (facturas)SituaciónCuentaP(x)

  1. Verificación: 0,008 + 0,092 + 0,9 = 1 ✓ (la tercera fila es simplemente 1 − 0,10, porque con A presente no importa B).
  2. E(X) = 0·0,008 + 25·0,092 + 50·0,9 = 2,3 + 45 = 47,3 facturas
  3. Σ x²P = 625·0,092 + 2500·0,9 = 57,5 + 2250 = 2307,5; Var = 2307,5 − 47,3² = 2307,5 − 2237,29 = 70,21
  4. σ = √70,21 = 8,379; CV = 8,379 / 47,3 = 0,177 ≈ 0,18. Como 0,18 < 0,2: baja fluctuación, y entonces tiene sentido usar la esperanza (47,3) como “facturación diaria típica”.

  3. AC, OPTN 2 (1-Variable Calc), recorre con ▼.

Qué sale: x̄ = 2,1 es E(X) · σx = 1,1358 es el desvío de X · sx = 1,1972 no se usa · n = 10 (solo es el factor de escala que elegiste, no tiene significado probabilístico). El CV: σx ÷ x̄ = 0,54.

Por qué σx: la tabla describe la distribución completa de X, no una muestra. Es la misma cuenta Σ(x − μ)²·P.

  • Olvidar “− μ²” en la forma corta: Σx²P = 5,7 no es la varianza; Var = 5,7 − 4,41 = 1,29.
  • Confundir Var con σ: si la pregunta es “varianza”, no saques la raíz; si es “desvío” o “variabilidad absoluta”, sí. Var = 1 y Var = 0 son los casos en que σ = Var.
  • Usar sx en la calculadora con una tabla de probabilidades: corresponde σx.
  • No chequear Σp = 1 antes de calcular: un P mal copiado arrastra toda la cuenta; y si falta una probabilidad, se despeja de 1 − (suma de las otras).
  • CV con Var en vez de σ, o interpretar CV = 0,54 como “54 autos”: es una proporción de la esperanza, sin unidades.
  • “Como mínimo un error” es P(X ≥ 1) = 1 − P(0) = 1 − 0,4 = 0,6 (TP3, ej. 1).

Practica: calcula antes de mirar las opciones

1. La distribución de X es: x = 0, 1, 2, 3 con P(x) = 0,1; 0,3; A; 0,2. ¿Cuánto vale A?

0,6 es la suma de las otras tres probabilidades. A es lo que falta para llegar a 1, es decir 1 − 0,6.
Las probabilidades deben sumar 1: A = 1 − (0,1 + 0,3 + 0,2) = 1 − 0,6 = 0,4.
Copiaste el valor vecino (P(3) = 0,2). Nada obliga a que A sea igual a otra probabilidad: se despeja de la suma = 1.
1 es el total de la distribución, no el valor de una sola probabilidad.
No hay motivo para repetir P(1): A se obtiene restando de 1 las otras probabilidades.

2. Con la tabla x = 0, 1, 2, 3 y P = 0,1; 0,3; 0,4; 0,2, ¿cuánto vale E(X)?

Es el promedio simple de 0, 1, 2 y 3. La esperanza pondera cada valor por su probabilidad: Σ x·P(x).
1 es la suma de las probabilidades (no de x·P). Eso solo sirve de chequeo.
6 es Σx = 0 + 1 + 2 + 3. La esperanza usa x·P(x), no la suma de los valores.
E(X) = 0·0,1 + 1·0,3 + 2·0,4 + 3·0,2 = 0 + 0,3 + 0,8 + 0,6 = 1,7.
Es el promedio de las probabilidades (1/4). No tiene relación con la esperanza de X.

3. Misma tabla (E(X) = 1,7; Σx²·P(x) = 3,7). ¿Cuánto vale la varianza?

Var = Σx²P − μ² = 3,7 − 1,7² = 3,7 − 2,89 = 0,81.
3,7 es Σx²P. Falta restar μ² (= 2,89) para obtener la varianza.
0,9 es el desvío (√0,81). La pregunta pide varianza.
2,89 es μ² (1,7 al cuadrado), solo una de las dos piezas de la fórmula.
Eso es la esperanza, no la varianza.

4. Una variable discreta tiene E(X) = 10 y σ = 3. Con la convención de la cátedra, ¿qué se concluye?

Dividiste E entre σ (10/3). El CV es σ/μ = 0,30.
El umbral de la cátedra no es 1, es 0,2. Con 0,30 la fluctuación es alta.
Elevaste σ al cuadrado (9) antes de dividir, es decir usaste Var/μ. El CV usa σ, no la varianza.
El CV no tiene unidades: es una proporción (0,30) de la esperanza, no una cantidad de unidades.
CV = σ/μ = 3/10 = 0,30. Supera 0,2, así que la variable tiene alta variabilidad relativa.

5. En la calculadora cargaste x = 0, 1, 2, 3, 4 con Freq = 1, 2, 3, 3, 1 (las probabilidades ×10). Pantalla: x̄ = 2,1; σx = 1,1358; sx = 1,1972. ¿Qué valor es el desvío de la variable X?

sx divide por n − 1 y se usa con datos de una muestra. Aquí n = 10 es solo la escala que elegiste (×10), no un tamaño muestral.
Eso es la media, o sea E(X). El desvío es otro estadístico.
La tabla de probabilidades es la distribución completa de X (no una muestra), así que se divide por n: σx. Coincide con Σ(x − μ)²·P.
n es la suma de las Freq que cargaste (1+2+3+3+1), solo un factor de escala.
Sí sirve: cargando probabilidades (o múltiplos enteros) como Freq, x̄ = E(X) y σx = σ de X.
